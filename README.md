# Student Management System

A command-line based Student Management System developed using Python. This project allows users to manage student records efficiently through a simple and interactive menu-driven interface.

## Project Overview

The Student Management System helps users perform essential student record management tasks such as adding, viewing, searching, updating, and deleting student information. Student data is stored in a text file, making the application lightweight and easy to use.

## Features

* ➕ Add new student records
* 📋 View all students
* 🔍 Search for a student by name
* ✏️ Update existing student information
* 🗑️ Delete student records
* 📊 Automatic grade calculation based on marks
* 💾 File-based data storage
